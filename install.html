Digital Front

Your space, your brand, your storefront. Flash it straight from this browser.

Enter the license key from your Gumroad receipt to unlock flashing. Haven't bought it yet? Get it here first.

  1. Plug your ESP32, ESP32-S3, or ESP32-C3 board (4MB flash minimum) into this computer over USB. Classic ESP32 boards without native USB need a CP210x/CH340 driver — already built into Windows 10+/macOS, occasionally a manual install on older Windows.
  2. Click Connect & Install below, then press and hold the BOOT button on your board right away — keep holding it.
  3. Pick your board's port from the browser's popup list. Keep holding BOOT until you see it actually start writing (a progress bar/percentage) — then let go.
  4. Wait for flashing to finish (about 30–60 seconds) — don't unplug.
  5. Once done, look for "Digital Front" in your Wi-Fi list and connect — the setup guide takes it from there. If nothing pops up within a few seconds, check Settings → Wi-Fi → ⓘ next to the network and make sure Auto-Login is on (this can get switched off if your phone's joined this network before), or open a browser and go to http://192.168.4.1.
Your browser doesn't support Web Serial. Use a recent Chrome or Edge on desktop (mobile browsers and Firefox/Safari aren't supported by this flashing method). This page needs to be served over HTTPS (or from localhost) for the browser to allow USB access — check how you're opening this page.
Stuck on "Connecting…" or it failed partway? Ensure to press BOOT before flashing.
